# delegation-templates

Fill-in templates for handing work to AI tools, assistants and services.

Hand-offs go wrong in small, predictable ways. The goal stayed in your head, "done" meant one thing to you and another to the helper, or the result came back and nobody knew how to check it. These templates put those things on the page. Each one is a plain Markdown file with blanks.

## How to use a template

1. Copy the file you need, or open it in your editor.
2. Fill the blanks. `____` is a blank, `- [ ]` is a box to tick, and lines that start with `>` are guidance.
3. Delete the guidance lines and anything that does not apply. A short, complete brief beats a long, padded one.
4. Paste the result into whatever helper you use: an AI chat, an assistant, a scheduling tool, a contractor's inbox, a colleague's message.
5. Keep your filled copy next to the work. You will want it again when the result comes back.

Each template says at the top who it is written for: the helper, you, or both. None of them depends on a particular product.

These are general starting points. For legal, medical, financial or safety-critical work, involve a qualified person as well.

## A sensible order

1. Write the brief and the definition of done before you send anything.
2. Settle permissions before the helper starts, and grant access, not secrets.
3. Review what comes back with the checklist, by rule and not by feel.
4. Give each repeating job a card. Write an away note before an absence.
5. Log decisions on the day you make them.
