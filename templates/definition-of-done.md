# Definition of done

Written for: you and the helper, before work starts. Attach it to the brief, or paste it in as the brief's section 7.
Use it when: a result can look finished without being finished.

> Guidance lines start with `>`. Delete them before you send.
> A good test: could someone who has never seen this task tell, from this page alone, whether the work is done?

## 1. The deliverable

- What exists when this is done: ____
- Format: ____
- Where it is, and what it is called: ____
- Who gets it: ____

## 2. Content checks

> Write them as things you can verify with your own eyes in a few minutes. "Good quality" is not a check.

- [ ] It answers this question: ____
- [ ] It covers this period or scope: ____
- [ ] Every number, date and name can be traced to a source listed at the end
- [ ] Terms are used as the brief defined them
- [ ] It contains each of: ____
- [ ] It leaves out: ____
- [ ] ____

## 3. Evidence the helper includes

- [ ] Sources: each file, page or system used, and which version
- [ ] Assumptions: anything it guessed
- [ ] Changes: everything it created, edited, moved or deleted
- [ ] Gaps: anything it could not do or could not confirm
- [ ] Open questions for me

## 4. How I will check

> Match the check to the risk. Where one wrong item would be costly, check every item.

- Check type: [ ] read everything  [ ] sample  [ ] signals only
- Sample rule, by rule and not by feel: ____ (for example every seventh item)
- Sample size: ____
- Items I always read in full: ____ (longest, shortest, oldest, strangest source, anything involving money)
- Time I have set aside: ____ at ____ (date, time and time zone)

## 6. Acceptance

- Accepted by: ____
- Accept by: ____ (date, time and time zone)
- If it passes: ____ (what happens next)
- If it fails: one round of rework with specific notes, then ____
- Most rounds of rework: ____
- Final call belongs to: ____

## 7. Ready-made lines by deliverable type

> Copy the lines that fit into section 2, and adjust them.

Research summary:

- [ ] The first paragraph states the answer and how sure it is
- [ ] Each claim has a source I can open
- [ ] Sources that disagree are shown side by side, not blended
- [ ] A short list says what could not be found

Spreadsheet or table:

- [ ] One total recomputed by hand matches
- [ ] The row count matches the input
- [ ] Units and dates are consistent within each column
- [ ] The source and the date of the data are written on it

Document or message draft:

- [ ] It is a draft: nothing was sent, posted or shared
- [ ] Names, dates, amounts and promises match my notes
- [ ] It sounds like me, or like ____
- [ ] Anything it invented is marked, or removed

Batch of files or items:

- [ ] The count of items out equals the count in, or the difference is explained
- [ ] A sample chosen by rule was read in full
- [ ] A list shows what was changed, item by item
- [ ] Nothing outside the batch was touched

Translation:

- [ ] Numbers, dates, names and units match the original
- [ ] The count of sections matches
- [ ] Key terms are used the same way everywhere
- [ ] Buttons, warnings and instructions were read by a native reader

Code change:

- [ ] The tests named in the task pass, and the output is shown
- [ ] Only files in scope changed
- [ ] The change can be undone: ____ (how)
- [ ] Follow-up ideas are listed, not done
