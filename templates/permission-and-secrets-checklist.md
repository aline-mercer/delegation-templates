# Permission and secrets checklist

Written for: you, before a helper starts. It applies to an AI tool, an assistant, a service or a person.
Use it when: a task needs the helper to reach an account, a folder, a system or a file.

> Guidance lines start with `>`. Delete them when you copy this.
> The rule in one line: grant access, not secrets.

## 1. Never paste these

Do not put any of the following in a brief, a chat, a ticket, a document, a screenshot or a file you share:

- Passwords and passphrases
- API keys, access tokens and session cookies
- Private keys and recovery phrases
- One-time codes and recovery codes
- Full card numbers, bank details and government ID numbers
- Anything marked secret or confidential that the helper does not need for this task
- Your own additions: ____

If a task seems to need one of these, stop and use section 2 instead.

## 2. Grant access instead

> Access can be narrowed, timed and taken back. A pasted secret cannot.

Choose the narrowest route that works:

- [ ] Invite the helper's own account to the folder, document or project, using the service's sharing feature
- [ ] Create a separate account or role for this work, with only the rights it needs
- [ ] Use a password manager or secrets manager that lends access without you reading the secret out
- [ ] Start read-only, and raise the level only when the work needs it
- [ ] Set an expiry date on the access
- [ ] Ask the helper to name, in advance, the exact access it needs and why

> If a helper asks for a password or key in plain text, treat that as a stop sign. Ask what it is trying to reach, and find another route.

## 6. Sharing files and screenshots

> Share what the task needs and nothing more. Swap details instead of deleting them, so the structure still works.

- [ ] I replaced real names, numbers and identifiers with realistic stand-ins

## 8. If a secret slips out

Do these in order, and do not wait to find out whether it was seen.

1. Revoke or replace it now: change the password, delete the key, expire the token.
2. Remove it from where it was pasted, and from any copies you know of.
3. Check the access record of the account for activity you do not recognize.
4. Tell whoever else relies on it: ____
5. Write down what happened and the time: ____
6. Fix the cause, so it does not happen again: ____
